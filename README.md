# Godot/Github Test!

Test out how GitHub works while I learn the basics of game engine coding in Godot.

## Description:
First game will be a small platformer about time-travel and fixing mistakes.

- Fluid Movement and momentum conservation
- Reversing time for only the player
- Story taking place in the world rather than over cutscenes mostly
    - Some cutscenes and character interactions throughout the levels
- Sonic style levels (zones with 2/3 each depending on how I feel)
- Cyberpunk asthetic, with different time zones being used for each zone
- Mature themes explored, not keeping kids in mind when designing dialogue and/or scenes

## Characters:
- Thea (Protagonist):
    - 19 y/o theif 
    - Steals a time travel device to go back and put herself on a better path in life
        - TTM's are common in this world, but still expensive for someone like her
    - Overshoots her destination and has to work her way back to her time
        - Builds relationships in each time period to help her get back to her time
        - Actively has to make the choice to leave everytime
            - Possibility for secret endings where she stays in the past?
    - Using her cybernetic implants, she's able to do some cool platforming to get back home
    - TTM's parts get stuck in different time periods, so she can only revert time back a few seconds (in game).
        - Levels will end with either a new toy to play with, or a new part for the machine
        - Zones will be built around the idea of multiple paths to encourage replayability, exploration, and player choice
            - Maybe a skill tree to upgrade your favorite implats?
                - If skill tree is implimented, all skills will have to be able to be unlocked by the end of the game
